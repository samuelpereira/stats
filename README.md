# stats

Web app for **collecting and reviewing live basketball statistics**.

## What it does

- **In-game collection** — record makes, misses, rebounds, assists, turnovers, steals, blocks, fouls, timeouts, and substitutions, with clock and periods
- **Box score and report** — player and team stats per game, shareable by link
- **Season** — team totals, results history, and head-to-head
- **Organisation** — clubs, seasons, teams, players, games, and users with role-based access

Built for tablet/phone use during games (including PWA install), with a local queue so entries are not lost if the network drops.

## Stack

Laravel, Livewire, Flux UI, Pest.
